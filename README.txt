RaevYoU Admin — обновлённая панель

Файлы:
- index.html — рабочая админ-панель с авторизацией и подключением к Supabase.
- style.css — графитовая тема в стиле developer workspace / Claude Code.
- script.js — логика чатов, отзывов, администраторов и обзорной страницы.
- preview.html — отдельный статический HTML-предпросмотр с демонстрационными данными.

Публикация:
Загрузи index.html, style.css и script.js в корень репозитория админ-панели, заменив старые версии. preview.html можно загрузить рядом — он не влияет на работу панели.

Предпросмотр:
Открой preview.html локально в браузере или после публикации по адресу /preview.html.

Supabase:
В script.js настроен URL проекта RaevYou review 2 и publishable key. Это публичный ключ для браузера; service_role/secret key не используется.

Важно:
Предпросмотр содержит демонстрационные данные и не подключается к базе. Рабочая панель — index.html. После публикации проверь вход, открытие чатов, отправку ответа, модерацию отзывов и управление администраторами.

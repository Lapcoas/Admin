RaevYoU Admin — первый запуск в базе RaevYou review

Рабочий проект Supabase:
https://supabase.com/dashboard/project/vlkwavhzujcrnrwoejyc

Первый запуск владельца:
1. Открой админ-панель.
2. Выбери «Первый запуск (владелец)».
3. Введи отображаемое имя, свою почту, придумай пароль и вставь одноразовый код запуска, который выдан в чате.
4. Если Supabase попросит подтвердить почту — подтверди её, затем войди.
5. Для последующих входов используй логин RaevYoU и созданный пароль.

Если регистрация не завершает вход:
1. Открой https://supabase.com/dashboard/project/vlkwavhzujcrnrwoejyc/auth/providers
2. Authentication → Sign In / Providers → Email.
3. Выключи Confirm email (Email confirmations), сохрани настройки.
4. Повтори регистрацию владельца в админ-панели.

Важно:
- Используется только проект RaevYou review (без цифры 2).
- Не запускай SQL из старых инструкций, относящихся к RaevYou review 2.
- Не передавай никому пароль или одноразовый код запуска.
